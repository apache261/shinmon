# Project history

Shinmon began as a private project in December 2024. The original local Git
history from the early development period is no longer available, so this
repository does not recreate unverified commits or dates for that period.

## Surviving record

- **December 2024:** Private development began. No original commit from this
  period survives in the current repository.
- **August 12, 2026:** A functional project snapshot survived in the local Git
  object database and was restored as commit `c0783eb`.
- **August 15, 2026:** The recovered snapshot was followed by the public mirror
  state and its deployment, dashboard, and documentation updates.
- **August 16, 2026:** The repository history and project documentation were
  reviewed and reconciled with the surviving snapshots.

Future changes use their actual commit dates. If an older authenticated backup
is recovered, its contents and provenance can be evaluated and incorporated
without inventing intermediate development history.
